# Third-party model notice
This service downloads OpenCV Zoo YuNet and SFace model files at image build time.
Preserve upstream attribution and review model/repository license terms before commercial deployment.
No model binaries are committed to this repository.

Source-only provenance record: official opencv/opencv_zoo commit
`48b10fa505aeb51fbd127fc60a5c660040e823b7`. Artifact SHA-256 and byte sizes
come from that commit's Git LFS pointer objects. The build verifies the actual
artifact bytes against these identities; source tests use synthetic constructors
and do not claim real inference, model quality, hardware acceptance or runtime certification.

Exact upstream YuNet and SFace license copies are preserved under `licenses/models/`
and copied into the image. Commercial deployment approval remains ungranted.
